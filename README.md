# CollabCanvas AI

## What this project does
This is a web app where students can study together. It gives you a shared blank space to draw, take notes, and ask questions with other students at the same time. 

## Main features
- **Shared Canvas:** Draw shapes, write text, and use a pencil to explain ideas.
- **Q&A Board:** Ask questions and let other students answer them.
- **Concept Blocks:** Add clear text blocks to organize your notes.
- **Focus Mode:** Change the screen to help you concentrate on studying.
- **Smart Tutor:** Get simple explanations, examples, and practice questions for any topic.

## How to use it
1. Open the website.
2. Share the room link with your friends.
3. Use the left menu to select drawing tools like pencil, rectangle, or text.
4. Click on the canvas to start drawing or writing.
5. Use the right menu to ask a question or use the smart tutor.

## What problem it solves
Sometimes it is hard to study with friends online because normal chat apps are not good for drawing diagrams or solving math problems together. This app gives you a shared board so you can learn together just like you would on a real whiteboard in a classroom.

## Note about the smart tutor
There is a smart tutor built into the app. If you are stuck, you can type a topic into the tutor. It will give you a direct answer, a simple explanation, a real-world example, and a small quiz to help you learn.
